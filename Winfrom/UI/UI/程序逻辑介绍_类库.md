# 程序逻辑

~~~
model层-->IDAL层-->DAL层-->BLL层-->UI层
~~~

## model层

~~~
	声明了基本字段 与重写了ToString方法, 同时根据声明类的需求 对构造函数进行了重写,保留无参构造函数,并初始化字段
~~~

## IDAL层

~~~
定义了基于用户  客户  日志类 必须要实现的规范
~~~

## DAL层

~~~
	实现接口的内部逻辑,只专注于具体数据的增删改查,注册
	使用静态列表完成不同类之间的数据传递,记录用户的id以及登录状态
	在日志类中为了解决用户操作单个记录随用户的登录登出状态来记录,引入可为空的日期类型,在用户退出后写入对应的操作退出日期,来完整写入整个登录周日用户有哪些操作

~~~

## BLL层

~~~
	引入权限管理来判断用户当前状态,如: 登录 退出 权限等级,以决定是否执行操作,并给出具体的提示
	对DAL层的状态进行分析,以获取运行状态,给出具体提示
	使用try语句捕获异常,避免程序崩溃
~~~

## 总结

~~~~
对部分逻辑进行封装,实现多层架,每层只关注上层状态金字塔结构,方法行为尽量保持单一
~~~~
